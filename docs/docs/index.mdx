<section id="image" className="feature">
  <div>
    <p className="eyebrow">01 / Define</p>
    <h2>Image</h2>
    <p className="feature-summary">A reusable definition of how an agent works.</p>
  </div>
  <div className="feature-detail">

An image packages **plugins, Agent Skills, and an ordered prompt template**.
Build it from an original directory containing `Tariboyfile.yaml`, inspect
exactly what the agent will receive, and reuse it across agents.

Start with the bundled `basic:latest` image or build one for a specific role.
Export runnable images to other hosts; keep the original source for rebuilds.
Harness, model, and effort belong to agent configuration.

[Explore images →](/images)

  </div>
</section>

<section id="agent" className="feature">
  <div>
    <p className="eyebrow">02 / Configure</p>
    <h2>Agent</h2>
    <p className="feature-summary">A named agent, with its own runtime and working directory.</p>
  </div>
  <div className="feature-detail">

Create an agent from an image, then choose **where it runs and which harness
it uses**. Configure its model, effort, working directory, and environment
independently of other agents.

Use Claude Code, Codex, or OpenCode installed on the selected host. Start
locally or connect a remote Linux host through your existing SSH configuration.

[Create your first agent →](/quickstart#4-create-an-agent) ·
[Connect a host →](/remote-hosts)

  </div>
</section>

<section id="interactive" className="feature">
  <div>
    <p className="eyebrow">03 / Collaborate</p>
    <h2>Interactive</h2>
    <p className="feature-summary">Work with the agent directly.</p>
  </div>
  <div className="feature-detail">

Open **Console** for a live session with the selected harness. Give
instructions, follow the work as it happens, and return to the same session
after switching away.

Interactive and Autopilot are independent: enable either or both.
For an ordinary terminal session without image instructions, choose
`bare:latest`, which keeps Autopilot off.

[Open Console →](/quickstart#5-use-console)

  </div>
</section>

<section id="autopilot" className="feature">
  <div>
    <p className="eyebrow">04 / Automate</p>
    <h2>Autopilot</h2>
    <p className="feature-summary">Keep work moving between conversations.</p>
  </div>
  <div className="feature-detail">

Run **bounded iterations on a timer or in response to durable messages**.
The host daemon manages the loop, so closing the desktop app does not stop it.

Inspect triggers, outcomes, usage, and cost in Activity. Set budgets and
deadlines, pause new iterations, or kill current work when needed.
Pausing Autopilot leaves the interactive session alone.

[Configure Autopilot →](/autopilot) ·
[Understand the controls →](/security-controls)

  </div>
</section>

<section id="team" className="feature">
  <div>
    <p className="eyebrow">05 / Coordinate</p>
    <h2>Team</h2>
    <p className="feature-summary">Independent agents. Shared work.</p>
  </div>
  <div className="feature-detail">

Group agents with a **lead, shared channels, and individually configured
roles**. Each member keeps its own image, harness, model, and runtime settings.

Native Tasks helps you decompose work, delegate it, track progress, and keep
questions and answers attached to the task. Transfer team configuration as
compose YAML or a portable archive, and transfer runnable images separately.

[Build a team →](/images-and-groups) ·
[Organize tasks →](/tasks)

  </div>
</section>
