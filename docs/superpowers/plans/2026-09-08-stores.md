# Stores Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement task-by-task.

**Goal:** Per-daemon Git/local Stores with CLI, API and server UI.
**Architecture:** A small catalog service stores name/source in SQLite and reads images from disk. Shared command registry exposes it and resolves a Store selector before existing image.build.
**Tech Stack:** Go, SQLite, Git/npm subprocesses, React/TypeScript.
**Spec:** docs/superpowers/specs/2026-09-08-stores-design.md

### Task 1: Catalog, shared commands and build selector

**Files:** create internal/stores/stores.go and stores_test.go; create internal/store/migrations/0040_stores.sql; create internal/commands/stores.go and stores_test.go; modify internal/commands/image.go and daemon.go; extend internal/cli/cli_test.go if needed.

**Interfaces:** persistence table image_stores(name TEXT PRIMARY KEY, source TEXT NOT NULL).
Return Store {name, source, path}, StoreImage {name, version, error?}, detail {name, source, path, images: []}.
GET /api/stores -> array; POST /api/stores {name,source} -> Store;
GET /api/stores/{name} -> detail; POST /api/stores/{name}/refresh -> detail;
DELETE /api/stores/{name} -> {removed:true}.
POST /api/images/build adds optional source selector parameter named source,
represented positionally by CLI; name and path become conditionally required.

- [ ] Write tests first using existing Store/registry fixtures. Missing store.add
  must fail explicitly before implementation, e.g.
  `if _, ok := BuildRegistry().Get("store.add"); !ok { t.Fatal("missing store.add") }`.
  Cover registration persistence, live reread, malformed entries, safe deletion,
  Git clone/pull conflict preservation, lock ordering and failure, selector traversal,
  default result version and compatibility. Use temporary Git repos and fake npx.
- [ ] Run make check and record expected missing-feature failures before production code.
- [ ] Implement catalog with DB methods, validated source grammar, owner-only managed
  clone paths, bounded context-aware subprocess calls and safe errors. Lock catalog
  operations through build preparation; reuse existing locks/patterns when possible.
  Do not follow image directory/Tariboyfile symlinks. Local sources are never removed.
- [ ] Register commands and group; resolve source selector before existing imageBuild
  freezes source. Supply default name, reject simultaneous path, restore locks root
  then image, release serialization only after source is safely frozen (holding through
  build is acceptable). Use image_version through current parser, no version parsing copy.
- [ ] Run make check GREEN, inspect diff, commit only backend files.
