# Промпт для Claude Code

Скопируйте всё ниже в Claude Code, запущенный в корне репозитория приложения. Рядом должна лежать эта папка (`design_handoff_console_slice/`).

---

Прочитай `design_handoff_console_slice/README.md` целиком, затем `design_handoff_console_slice/reference/tariboy-theme.css`. HTML-файлы в `reference/` — дизайн-референсы (не код для копирования): это прототипы вида и поведения, которые нужно воспроизвести в нашем React + Tailwind + shadcn окружении, нашими существующими компонентами.

Мы внедряем новый стиль **вертикальным срезом**: одна страница целиком — консоль оператора (топбар, сайдбар агентов, плавающий остров контента, шапка агента, табы, фильтр-бар, таблица задач в двух режимах). Переструктурировать компоненты разрешено.

Работай строго этапами, каждый — отдельный коммит, после каждого останавливайся и показывай, что изменилось:

1. **Тема.** Замени текущие shadcn-neutral значения токенов на блок из `reference/tariboy-theme.css` (light + `.dark`), включая новые токены `--status-*`, `--lift`, `--panel-radius`, `--font-mono`. Ничего кроме значений токенов на этом шаге не меняй. Покажи, какие экраны затронуло.
2. **Оболочка.** Топбар 42px без бордера, сайдбар 268px на фоне `--background` без бордера, контент — остров `--card` / `--panel-radius` / `--lift`. Разделы README «Console shell» и «Куда это ложится в репозитории».
3. **Примитивы среза.** Строка агента, строка задачи, статус-пилюля, приоритет — по разделам 2, 3 и 6 README. Статусные правила («заливку получает только живое и требующее внимания») реализуй как одно место в коде, а не как ad-hoc классы по строкам.
4. **Таблица задач и фильтр-бар.** Разделы 5 и 6, оба режима (agent / all), поведение фильтров и раскрытия из «Interactions & Behavior».

На шаге 1 заодно выполни оба пункта из раздела README «Заодно починить в стилях»: поднять тематические CSS-переменные из селекторов компонентов в `:root`/`.dark` и перенести аннотации `/* @kind … */` на строку объявления токена.

Правила:
- Только существующие компоненты (`Button`, `Badge`, `Tabs`, `Input`, `ScrollArea`, `Card`, …). Новый компонент — только если в README описан примитив, которого нет.
- Цвета — только через токены. Никаких hex и новых оттенков в разметке; `color-mix(in oklab, …)` для прозрачных заливок, как в README.
- Плотность и размеры брать из README буквально (строки 30px, кнопки 24/26/28px, пилюли 17/19/20px).
- Все идентификаторы, длительности и время — моно + `tabular-nums`.
- Две тени, не больше: `0 1px 2px oklch(24% .03 75/.10)` и `--lift`.
- Тёмная тема на этом срезе должна просто работать на токенах; отдельная доводка dark mode — следующая задача, не делай её сейчас.
- Если референс и текущая реализация расходятся в поведении (а не в виде) — сохраняй текущее поведение и скажи об этом.

В конце дай список изменённых файлов и то, что осталось несовпадающим с эталоном.
